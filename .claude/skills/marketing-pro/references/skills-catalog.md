# Capability catalogue — 163 Marketing Pro skills

Routing table distilled from Digital Marketing Pro v3.31.1 `skills-index.json` (shipped verbatim at `../assets/skills-index.json` — grep it for the full descriptions and script/gate/cross-reference metadata).

**Tier** is the upstream depth contract: **E** = the upstream skill executes real Python scripts (108 skills), **M** = its output is routed through the quality machinery (12), **G** = structured guidance (43). The scripts are *not* bundled here, so treat an E-tier row as "do this analytically, state the method and its limits" — see `../SKILL.md` § What is and isn't bundled.

`Gates` names what must pass before the output is publishable. Honour it.
